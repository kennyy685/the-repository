Truncation rule everywhere: white-space:nowrap; overflow:hidden; text-overflow:ellipsis on one line, never a wrapped 2nd line except sub-lines that are allowed to wrap (coach, empty body).

Found here, both unmodified ds.css: .top h1 has no white-space:nowrap or ellipsis, so a long title wraps to 2 lines instead - and since .top is a fixed 52px with overflow:visible, the second line spills past the bar (see above - it overlaps the nav that follows). .btn has white-space:nowrap but no overflow/ellipsis rule at all, by design ("verb labels only") - this string still fits, but a longer one would spill past the button's rounded edge with nothing to catch it. Neither is fixed here - flag to the Builder before a real screen ever needs a title/label this long.

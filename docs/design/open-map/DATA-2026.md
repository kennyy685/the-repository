# Open map data: `data/storms-2026.json` (Path step 4)

Real public data for the open map, replacing the mockup's SAMPLE storms. Built by `python3 hh.py season`
(`hailhunter/season.py`, ~35 s, own network step: `refresh`, hud.json and the 6:54 AM Storm Watch are untouched).
Refresh it in the morning run: `python3 hh.py season` (add `--no-mesh` to skip the radar grids, `--offline` for cache
only). Area: eastern Nebraska, bbox `[-97.9, 40.35, -95.3, 42.2]` (Columbus to Omaha, Lincoln to Norfolk), NE only,
hail >= 0.75 in. Settings: `config.py` `season`.

Rules: no owner names, no houses (homes on the map stay samples until knocking starts), no report free text.
Never say "insured": the fields and labels say **likely insured**, an area estimate from Census numbers.

## Top level
| field | what |
|---|---|
| `v`, `season`, `as_of`, `today` | version 1, year, build time (UTC), the day `days_ago` counts from |
| `real` | `true`: the map can show the REAL PUBLIC DATA tag instead of SAMPLE |
| `area` | `{name, bbox, states, min_size_in}` |
| `note` | `{en, es}` one line for the map footer |
| `sources[]` | `{id, name, url, count}` for lsr, spc, ncei, radar, mrms, census |
| `census_vintage` | ACS 5-year end year (e.g. "2024" = 2020-2024) |
| `storm_days[]` | newest first: `{date, reports, max_in, first_local, last_local, towns[], radar_cells, mesh_max_in, zones[]}` |
| `zones[]` | ranked hot zones (below) |
| `areas[]` | towns with >= 300 homes (below) |
| `reports[]` | every ground report (below) |
| `errors[]` | `{part, error}` per source that failed this run (the rest still ship) |

`date` everywhere = storm day, 12Z to 12Z (7 AM to 7 AM CDT), same as the engine; an 8:30 PM storm stays on its day.

## `reports[]`
`{id, date, date_local, time_local, utc, lat, lon, size_in, place, location, county, state, by, sources[]}`
- `sources`: `lsr` (NWS Local Storm Report), `spc` (on SPC's daily list), `ncei` (NOAA Storm Events official record).
  The same hail from several lists is ONE report with several sources (within 4 km and 30 min).
- `by`: who reported it ("Trained Spotter", "Law Enforcement", "Public", ...), empty when unknown.
- `place`: town name ("2 N Fremont" -> "Fremont"); `location` = the original text.

## `zones[]` (hot zones)
| field | what |
|---|---|
| `id` | `<date>~<town slug>` (e.g. `2026-04-23~lincoln`, `-2` when repeated) |
| `kind` | `ground` (reports within 10 km of the zone's biggest one) or `radar` (MRMS >= 1.25 in over >= 4 km2 where nobody reported) |
| `rank`, `score` | 0-100, higher = better place to knock |
| `score_parts` | `{size, agree, recent, homes}` each 0-1; weights 0.4 / 0.2 / 0.2 / 0.2 |
| `agree_pct` | how much the sources agree (0-100), for the proof card |
| `date`, `days_ago`, `time_local` [first, last], `first_utc`, `last_utc` | when |
| `name`, `near_town`, `towns[]` | reported town, biggest town in the zone, towns in its reports |
| `center {lat, lon}`, `radius_km`, `outline` | map shape; `outline` = closed [[lon, lat]] ring 2 km around the reports (null for radar zones) |
| `hail_in`, `hail_basis` | biggest ground report, or the radar estimate when `hail_basis` = "radar" |
| `mesh_in` | biggest MRMS radar hail size in the zone (null without a grid) |
| `reports`, `report_ids[]` | ground reports in the zone |
| `sources[]` | lsr / spc / ncei / radar (NEXRAD signatures) / mrms |
| `radar_cells`, `radar_max_in` | NEXRAD hail signatures near the zone that day |
| `signals` | likely-insured signals for the zone's block groups (below) |
| `why[]` | `[sign, {en, es}]`: +1 good, -1 bad, 0 neutral; one plain line each |

## `signals` (zones and areas)
All from the US Census ACS 5-year; `null` when the Census has no number (never a made-up default).
| field | what | table |
|---|---|---|
| `homes` | housing units | B25001 |
| `owner_homes`, `owner_share` | homes lived in by their owner, share of occupied homes | B25003 |
| `mortgage_share` | owner homes with a mortgage (lender requires coverage) | B25081 |
| `recent_buyer_share`, `recent_buyer_since` | owners who moved in since that year: the recent-sale proxy | B25038 |
| `median_year_built` | typical year built (homes-weighted): roof-age hint | B25035 |
| `built_before_2000_share` | share of homes built before 2000 | B25034 |
| `likely_insured` | `{score 0-100, level high/medium/low, label {en, es}, parts}`; score = owner share x (0.75 + 0.25 x mortgage share) | |
| `source` | e.g. "US Census ACS 2020-2024 5-year, block groups" | |

Zones use the block groups whose middle is inside the zone; areas use the town's own Census row.

## `areas[]` (towns)
`{id, name, geoid, center {lat, lon}, reach_km, hail {storm_days[], reports, max_in, last_date, last_max_in}, signals}`,
biggest town first. `hail` = this season's reports within `reach_km` of the town's middle.

## Honest limits
- Ground reports are where someone reported, not every street that got hail; radar zones fill some gaps.
- MRMS MESH often reads high; radar-only zones count their size x 0.8 in the score.
- NCEI Storm Events runs months behind (2026 file covers early season); LSR/SPC are near real time.
- Real sale records aren't public in bulk: `recent_buyer_share` (Census "moved in since") stands in for recent sales.

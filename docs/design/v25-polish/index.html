Top 15 fixes, by impact

The builder works them in this order. The full screen-by-screen critique (every screen, word counts, cut targets) is in the repo: docs/design/v25-polish/critique.md.

01Real dark mode + on-ink

Fixes the blank buttons and the muddy look you saw.

02Vector map on Now and Knock

Streets, lots, route along the street, numbered stops, you-dot, heat.

03Lead: next step first

681 → about 110 words; the rest behind 3 rows.

04One type scale

8 sizes, 3 weights. Mono only for tiny labels.

05One icon set

No more ⇄ → ✓ ⋯ typed as text.

06Each fact once

No second hail line, year, step or heading.

07Knock header

Rules chip, one ⋯, "Stop 3 of 25 · 23 to go".

08Answer buttons

Icon + word + hint. Only Booked is orange.

09Docked Right Hand

A chat bar above the tabs, never over cards.

10Money: one figure

Owed first, a split bar, then claims. Empty = 8-step path.

11List rows

Address / action / chip. Show 3, then "See all".

12Status chips

Flag + "2 days late", not red mono text.

13Bottom bar

Bigger icons, "Add" labeled, one badge.

14Loading + empty states

Skeletons in the real shapes; empties that say what's next.

15Sheets

Round × close, no orange ring on open, one grab handle.

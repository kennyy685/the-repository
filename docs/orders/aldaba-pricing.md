# Aldaba Pricing Shape

**Decision:** Hybrid flat-base-plus-seat model.
Flat tier (covers small crew base) + per-seat overage.

**Why:** Roofr and CompanyCam — the two tools actually winning in this space — both price this way,
not pure per-seat. Fits HMP's own size better; doesn't punish adding crew members.

## Draft tiers (not decided yet — price ranges only)

- **Starter** (1-3 users): $99-149/mo flat
- **Crew** (up to 6 users): $249-299/mo flat, +$25-35/extra seat beyond 6
- Add-on per feature (e.g., reports, states): $13-19/item/mo

**Pricing justifies against replacing 2-3 separate tools** (photo tool + canvassing + hail data),
not against one competitor alone.

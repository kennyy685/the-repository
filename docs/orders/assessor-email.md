# Assessor bulk-data emails (3 counties) - 2026-09-29

**What Kenny does:** copy one block below, paste into email, send from his own address. Nothing here was sent.
**Why:** county assessor data (year built, class, sale date) = roof/siding age + "likely insured" homes. Free public record.

**Counties:** Dodge (Fremont, home base), Washington (Blair), Saunders (Wahoo). Douglas/Sarpy already have public GIS layers
(see round 48), so no email needed there.

**Free direct download found:** none for these 3. Each has a look-up-one-parcel site only
(Dodge: dodge.nebraskaassessors.com + dodge.gworks.com; Washington: washington.gworks.com + beacon.schneidercorp.com;
Saunders: saunders.nebraskaassessors.com + saunders.gworks.com). So the email is needed. Statewide sales file (arm's-length sales,
all counties) is also by email: PAT.SalesFileREQ@nebraska.gov (Neb. Dept. of Revenue, Property Assessment Division).

**Law basics (Neb. Rev. Stat. 84-712 to 84-712.09, verified by search summary; re-read on nebraskalegislature.gov before quoting):**
public records are open to any person; office may charge only the **actual added cost** (copies, computer run time, programming);
if the estimate is over **$50** they may ask for a deposit first; no reason for the request is required; if they refuse or
overcharge you can petition the Attorney General (84-712.03). Fees are unconfirmed for each county: the emails ask.
Owner names are NOT requested (HMP rule), so the owner-privacy question mostly disappears.
Note: homestead is not an "owner lives here" flag (round 62); the emails ask for it anyway, plus mailing-vs-situs address is NOT asked.

To: **assessor@dodgecountyne.gov** (listed on dodgecounty.nebraska.gov/contact) · 435 N Park Rm 202, Fremont · 402-727-3911

```
To: assessor@dodgecountyne.gov
Subject: Public records request - residential parcel data export (Dodge County)

Hello Ms. Marshall,

I am requesting a copy of public records under the Nebraska public records law (Neb. Rev. Stat. 84-712). I am with HMP Siding & Roofing LLC in Fremont and will use the data for contractor marketing research (finding older homes that may need roofing or siding work).

Could you please send a bulk export of all residential parcels in Dodge County with these fields:
- Parcel ID
- Situs (property) address, including city and ZIP
- Year built (and effective year built, if you keep it)
- Property class / use code
- Homestead exemption flag (yes/no)
- Last sale date and sale price
- Exterior wall type and roof type/cover, if those fields exist
- Square footage and number of stories, if available

I do not need owner names or owner mailing addresses.

Preferred format is CSV (or Excel). A shapefile or geodatabase with the same fields is also fine. If you already have this as a standard extract from your CAMA system, that works.

Please tell me:
1. Whether you can provide it, and how (email, download link, or disc).
2. The fee, if any, and how to pay. Please quote it before you run it.
3. How current the data is and how often it updates.

Thank you for your help.

Kenny Cruz

```

## Notes
- Answers can take up to a few business days (statute sets a short response window; confirm text on the legislature site).
- Expect a "we don't do exports" from a small office: reply asking for a **printed/PDF list** or the **CAMA vendor's** (Vanguard/gWorks) standard export. Phone follow-up is fine.
- Can't verify from here: real fees, whether offices refuse bulk. Sources: dodgecounty.nebraska.gov/contact, washingtoncountyne.gov/assessor, saunderscounty.ne.gov/county-assessor, revenue.nebraska.gov/PAD/county-assessors-and-parcel-search, nebraskalegislature.gov statutes 84-712.

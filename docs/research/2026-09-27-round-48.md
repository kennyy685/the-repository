## Details

### T164 - Douglas & Lancaster County parcel data (owner-occupied signal)
- **Douglas County** (`dcgis.org`): `https://dcgis.org/arcgis/rest/services` itself 404s (round 41's
  "reachable" was the bare domain, an IIS default page, not real services) - the actual working path is
  **`https://dcgis.org/server/rest/services/vector/Parcels_public/FeatureServer/0`**. Schema fields:
  `OWNER_NAME`, `ADDRESS1`, `ADDRESS2`, `OWNER_CITY`, `OWNER_STAT`, `OWNER_ZIP` (owner's mailing address) vs.
  `HOUSE`, `STREET_DIR`, `STREET_NAM`, `STREET_TYP`, `PROP_CITY`, `PROP_ZIP` (the property's own site
  address), plus `BLDG_YRBLT` (year built), `CLASS` (property class code, meaning not yet decoded), `ACRES`,
  `SQ_FEET`. A live test query returned a real row (owner in Omaha, property in unincorporated "Douglas
  County" with a different zip - a plausible absentee-owner example, though `ADDRESS1` was blank on that
  particular row, so field completeness needs checking across more rows before trusting it fully).
- **Lancaster County** (`gis.lincoln.ne.gov`, same "bare domain reachable, base path wrong" issue as Douglas):
  the real endpoint is **`https://gis.lincoln.ne.gov/integration/rest/services/Assessor/TaxParcels/MapServer/0`**
  (a public mirror also exists at `.../public/rest/services/Assessor/ParcelLinesAerial/MapServer/0`, same
  fields). Fields: `OWNERNME1`/`OWNERNME2` (owner name), `PSTLADDRESS`/`PSTLCITY`/`PSTLSTATE`/`PSTLZIP5` (owner
  mailing address) vs. `SITEADDRESS` (property's own full address, already a single formatted string) -
  **plus `RESYRBLT`** (residential year built - already usable the same way `nbhd.py` uses ACS year-built
  today, but per-parcel instead of per-block-group) **and `CLASSDSCRP`** (a plain-text property class, e.g.
  "Residential Improved" - easier to filter on than Douglas's single-letter code). A live test query returned
  a real owner-occupied example: site address "21200 SW 72ND ST, CRETE, NE" and postal address "21200 SW 72
  ST, CRETE, NE" - matching street on both sides, i.e. exactly the signal T23 needs, live-confirmed working.
- Both are standard Esri ArcGIS REST services, no login/API key needed for the schema or small test queries
  (3-record `resultRecordCount` queries worked with no auth). Bulk-pull limits (`maxRecordCount`, pagination)
  weren't tested this round - see ranked item 3.
- Sarpy County's own working layer (`Cadastral/LandRecordsSearch`, layer 5 "Tax Parcels") wasn't re-tested in
  detail this round since round 41 already confirmed Sarpy wired via `Parcel_Sales2` - only re-confirmed the
  service directory still resolves (`Cadastral` folder present, `LandRecordsSearch` FeatureServer/MapServer
  both listed).

### Tortious interference - the Nebraska legal line for "already signed with another contractor"
- **The case**: *George Clift Enterprises, Inc. v. Oshkosh Feedyard Corp.*, 306 Neb. 775, 947 N.W.2d 510
  (Neb. 2020) - a 2020 Nebraska Supreme Court decision on tortious interference with a contract/business
  relationship/expectancy (a real-estate listing dispute, not roofing, but Nebraska applies the same doctrine
  regardless of industry). Same citation independently confirmed by Justia, CourtListener, FindLaw and vLex -
  strong convergence, though this session couldn't open any of the four to read the opinion's own words
  (all four blocked, see Watch out).
- **The elements** (converged across multiple Nebraska-focused legal sources, including an Omaha firm,
  Croker Huck): (1) a valid contract or business relationship/expectancy existed, (2) the other party knew
  about it, (3) an intentional, unjustified act induced or caused a breach or termination of it, (4) that
  caused (5) actual damages. "Unjustified"/"improper means" is judged by Restatement-style factors: the
  nature of the conduct, the actor's motive, competing interests, and whether the conduct was truthful,
  competitive information vs. fraud, coercion, defamation, or misuse of confidential information.
- **What this means for HMP's script (round 36, `data/objection_scripts_2.json`)**: the existing script -
  state the homeowner's 3-day cancel right as plain fact, never coach or push them to cancel, no disparaging
  the other contractor - already sits inside the "truthful information" / "legitimate competition" safe
  harbor these sources describe. A company that wins business through better pricing, product, or service is
  lawful competition; one that induces a breach through pressure, false statements about a competitor, or
  active coercion is not. Nothing here says HMP needs to change its script - it gives a real citation to point
  to if the question ever comes up, instead of "it sounds legally careful."

## Watch out
- The tortious-interference citation and elements are **WebSearch-summary sourced, not directly fetched**:
  every case-law and law-firm domain tried this session (crokerlaw.com, horganlawfirm.com, law.justia.com,
  courtlistener.com, nebraska.gov court pages, leagle.com, supremecourt.nebraska.gov) failed with
  `CONNECT tunnel failed, response 403` via both WebFetch and curl - a session-level block on that whole
  category of site, not a broken link. Treat the case name/citation as high-confidence (four independent
  sources agree on the exact volume/page/year) but not yet primary-verified word-for-word.
- Douglas County's parcel `ADDRESS1` field was blank on the one sample row pulled - don't assume every parcel
  has a populated owner-mailing address; Code should sample more rows (or check a documented null-rate) before
  trusting the signal at scale, and fall back to the existing neighborhood-level estimate when the field is
  empty rather than guessing "renter."
- Never use per-house owner/mailing data for anything customer-facing or to imply HMP already knows who
  lives where before knocking - it's a door-list ranking signal only, same handling CLAUDE.md already sets for
  the neighborhood-level version.

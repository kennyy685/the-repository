**For context (already known, round 39/56, unchanged):** Fremont requires both a building permit
and the city's own contractor registration (Council Resolution 2019-049 - $65 fee, $250,000 liability
insurance naming the City as additional insured, proof of NE Dept. of Labor registration) on top of the
state Contractor Registration Act. All four cities sit on top of that same state layer - **Nebraska
Contractor Registration Act** (`dol.nebraska.gov/conreg`, fetched directly this round): any contractor
doing work on property that isn't their own must register with the NE Dept. of Labor, **$40/year**
(increasing from a lower fee Aug. 1, 2026), and anyone with employees must carry workers' comp insurance
(ACORD 25 certificate, NE DOL as certificate holder). This state layer applies everywhere in Nebraska
regardless of city - it's the one number in this whole table that's fully verified for all three cities
at once.

### T185: Cold-weather build limits - now in `docs/research/2026-09-26-off-season-plan.md`

The off-season plan's original line 6 had asphalt/vinyl/fiber-cement numbers that were looser and, in
vinyl's case, slightly different from round 52's own more careful table (20-35°F vs. 35-40°F). This
round replaces that line with a dedicated table (same file, new "Cold-weather build limits" section)
using round 52's sharper numbers plus one genuinely new primary source found this round: **NRCA's own
"Cold Weather Application" article** (Professional Roofing magazine, Dec. 2012, by Mark S. Graham, NRCA's
associate executive director of technical services - read directly as a PDF this round via `nrca.net`).
It confirms, in NRCA's own words, that self-sealing asphalt shingles' "sealing strips may not immediately
activate if installed in cold weather" and that "manufacturers suggest hand-tabbing shingle tabs during
installation... until the shingles' self-seal strips activate" - a real trade-association primary source
for the *mechanism*, even though it doesn't quote an exact "40°F" number for shingles specifically (that
exact figure is ARMA's, and ARMA's own page was blocked again this round, same as prior rounds).

The Hardie ColorPlus 30°F figure and the vinyl 35-40°F figure both remain **unverified against their own
manufacturer/association pages** - jameshardie.com's root, blog and FAQ are directly reachable this round
(confirming round 52's finding) but the actual Best Practices PDF still isn't; `vinylsiding.org` was
outright blocked this session (a new attempt, previously untried). Both numbers are consistent across
several independent contractor sources across two separate rounds, which is worth something, but isn't
the same as reading the manufacturer's own page.

Added to the plan: a one-line rule for FilthE and the boss - if the forecast won't hold above the
coldest material's floor for every day of the install, book the contract and deposit now and schedule
the actual build for the first stretch of spring weather above that floor.
